# 2스테이지 웨이브·벽 배치 메모

> 2026-11-19 설계 기록이다. Unity 밖 시뮬레이션 결과이며 Play Mode로 확인하지 않았다. 수치는 임시 값이다.
> 2차 조정에서 진영 컨셉과 사용 가능한 스킬을 반영했다. 바로 아래 "2차 조정"이 현재 `Waves2`이고, 그 아래 "웨이브별 결과 (마법 없음)" 표는 1차 편성 기록이다.

## 2차 조정: 1·2번 스킬만, 진영 컨셉 반영

### 전제
- 플레이어는 **1번 공격력 버프**와 **2번 힐**만 쓴다고 가정한다. 이동속도 버프·방어막·도발은 없다.
- **고블린**: 능력치는 낮고 물량이 많다. **언데드**: 평균적인 능력치를 갖는다.
- 언데드 공용 유닛(해골·좀비·궁수·리빙 아머·사신)은 1·3·4스테이지 씬에서도 쓰므로 수치를 그대로 둔다. 해골(전력 0.91)과 좀비가 이미 평균 기준이다.

### 바꾼 유닛 능력치 (`EnemyCatalog.asset`)
> 이 표는 2차 조정 당시 값이다. 이후 전 유닛 수치를 개편했으므로 현재 값은 [유닛 밸런스](balance.md)의 "유닛 수치 (2026-11-19 전면 개편)"를 본다. 개편 후 같은 편성으로 다시 돌린 코어 도달 합계는 벽 없음 148, R5 85다(개편 전 152 / 85).
아래 4종은 `Waves2`에서만 쓰여서 다른 스테이지에 영향이 없다. 전력 = 체력 × DPS ÷ 1154.

- 오크와 투석병은 공용이라 그대로 두고, `Waves2`에서 오크 수를 1~2명으로 제한했다.
- 공격력 버프는 고정 +15라서 공격 8인 졸병은 23(약 2.9배)이 된다. 약한 무리에 버프를 거는 선택이 뚜렷해진다. W5의 리빙 아머(방어 3)를 상대로 졸병 피해는 5에서 버프 후 20이 된다.

### 결과 (코어 도달 = 고블린 + 언데드)
"마법"은 시뮬레이터에 넣은 단순 플레이어 정책이다. 1초에 최대 1번, 교전 중 양쪽 힘(체력 × DPS 합)이 0.4배 이하로 벌어지면 열세 진영 쪽에 시전한다. 반경 1.4칸 안의 피해가 35% 이상이면 힐, 아니면 공격력 버프를 쓴다.

| 웨이브 | 벽 없음 | R5 | R5 + 마법 |
| --- | --- | --- | --- |
| W1 | 8+4 | 3+1 | 3+1 |
| W2 | 7+3 | 2+2 | 8+0 |
| W3 | 8+5 | 4+5 | 4+2 |
| W4 | 7+5 | 7+3 | 7+3 |
| W5 | 8+4 | 5+2 | 5+2 |
| W6 | 7+5 | 3+4 | 4+3 |
| W7 | 12+6 | 9+3 | 8+3 |
| W8 | 7+8 | 4+3 | 5+4 |
| W9 | 11+10 | 7+5 | 7+3 |
| W10 | 18+9 | 6+7 | 9+5 |
| **합계** | **152** (코어 120 → 패배) | **85** | **86** |

- 벽 없이는 9웨이브쯤에 진다. 벽은 필수이고, R5만으로도 생존한다.
- 코어 도달은 머릿수로 세므로, 물량이 많은 고블린이 도달 수 대부분을 차지한다. 고블린을 줄이려면 언데드를 버프·힐해서 고블린 무리를 녹이는 것이 기본 풀이다.
- 단순 정책은 마법 없이 할 때보다 나아지지 않았다. W2는 고블린 버프로 판이 뒤집혀 고블린이 8명 도달했다. "열세 쪽을 도와 비등하게"가 지나치면 오히려 이긴 쪽이 새어 나간다. 사람의 판단이 필요한 지점이라 Play Mode로 확인한다.
- W4: 고블린 원거리가 거의 죽지 않는다(8명 중 7명 도달). 언데드 궁수와 해골에 버프를 거는 풀이가 되는지 본다.
- W3·W8: 이동속도 버프가 없어서, 빠른 돌격병은 벽으로 길을 늘려 붙잡을 수밖에 없다.

### 재현 (2차)
1차의 `StageCheck.cs` 빌드에 `MAGIC=1`(1·2번 스킬 자동 시전)과 `RATIO`(개입 기준, 기본 0.6, 위 결과는 0.4)를 더했다. 수정본과 입력은 [증거 폴더](../ai-use/evidence/20261119-stage2-waves/)에 있다: `StageCheck.cs`, `Stage.csproj`(저장소 상대 경로), `w5.txt`(현재 편성), `run2.sh`(편성×벽×마법 일괄 실행), `patchcat.py`(카탈로그 수치 임시 변경).

```bash
cd ai-use/evidence/20261119-stage2-waves && dotnet build -c Release -o /tmp/stage
CATALOG=<EnemyCatalog.asset> STAGE=<Stage2_Temp.asset> RATIO=0.4 MAGICS="0 1" WALLSETS="none 12,16_3,3_2,12_13,11_16,17" bash run2.sh w5.txt
```

`run2.sh`는 자기 폴더의 `bin/Release/net10.0/Stage.dll`을 실행하므로 출력 경로를 맞춘다.

## 다음 테스트에서 볼 것

- **W3**: 돌격병(속도 2.5)과 좀비(1.2)는 벽이 없거나 (3,3) 하나만 있으면 교전이 0번이다. R5에서도 언데드 6명이 전부 도달한다. 이동속도 버프를 언데드에게 거는 것이 의도한 풀이인지 확인한다.
