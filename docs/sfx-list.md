# SFX 제작 목록

현재 구현을 기준으로 한 제작 제안이다. 확정된 사운드 기획은 아니며, 아래 개수는 원본 음원 파일 수 기준이다. BGM은 별도 작업으로 둔다.

2026-11-19 Unity AI로 **1차 신규 23개 시안**을 생성했다. 기존 `Assets/Audio/SFX/Casual_Hit_01.wav`를 포함해 기본 세트는 총24파일이다. [생성 결과와 미리듣기](audio/unity-ai-sfx.md)를 참고한다. 현재 게임에 연결된 것은 기존 공통 타격음이며, BattleSoundPlayer → SoundManager에서 볼륨0.24와 동일 클립 동시6개 제한으로 재생한다. 신규 시안은 청취 검토와 이벤트 연결이 필요하다.

**16종, 총24파일** 제안. 현재 타격음1개를 재사용하면 **신규23파일**이다. 우선 UI/핵심 결과/마법 소리를 붙이고, 반복 빈도가 높은 타격·발사·건설에 변주를 확보한다. 음원이 없으면 연결된 이벤트도 무음으로 동작하도록 유지한다.

마법은 시전 결과가 확정된 `OnSpellResolved`에서 성공 여부와 실제 적용 대상을 확인해 한 번 재생한다. 범위 안 유닛 수만큼 같은 소리를 중복 재생하지 않는다. 실패 메시지와 성공 시전음을 동시에 내지 않는다. 활/투석의 별도 발사 소리는 화면 쪽의 공격 연출 신호 연결이 필요하며, 원거리 공격에 공통 타격음만 쓰는 현재 재생과 구분한다.

## 2차 — 전투의 재질과 팩션 구분

| 항목 | 제안 수 | 용도 |
| --- | ---: | --- |
| 무거운 명중 | 2 | 대형 유닛·강한 일격용. 매 공격마다 공통 타격음과 겹쳐 틀지 않고 교체하는 방향 |
| 방어막 명중 | 2 | 방어 버프가 적용된 대상을 때릴 때. 현재 방어막 시각 효과와 연결 |

| 팩션별 사망 | 각2, 총8 | 녹색 무리·언데드·짐승·용족/악마의 큰 구분부터. 유닛 개별 음성은 이후 확장 |

사망음은 실제 전투 사망에만 사용한다. 코어 도달로 사라지는 적에는 코어 피해음을 사용해 사망음이 겹치지 않게 한다.

## 후순위 또는 기능 연결 후

- **최종 승리음**: 승리 UI는 존재하지만 현재 DefenseBattle은 라운드 종료 후 다음 라운드로 넘어가는 구조다. 최종 승리 판정 연결 시 별도 이벤트로 추가한다. 웨이브 종료음과 구분한다.
- **코어 위험 알림**: 체력 기준과 재알림 간격을 정한 뒤 추가한다. 프레임마다 반복하지 않는다.
- **발걸음·유닛 대사·개별 스폰 소리**: 군중 전투에서 반복이 과해지기 쉬워 후순위다.
- **환경 루프**: 낙엽·눈밭 등 맵 분위기용. 전투 SFX와 별도로 믹싱한다.
- **UI 호버·범위 조절 틱음**: 기본 클릭/취소로 충분한지 확인한 뒤 추가한다.

## 제작 및 연결 기준 — 제안

- 무겁고 사실적인 고어보다 짧고 둥근 스타일라이즈드 톤을 우선한다. 전투음이 겹쳐도 날카롭거나 피곤하지 않게 한다.
- 타격·발사·클릭은 약0.1~0.35초, 건설·마법은 약0.3~0.8초, 라운드/결과음은 약0.6~1.8초부터 시험한다. 긴 앞 무음과 긴 잔향은 피한다.
- 원본은 WAV 48kHz/24bit를 제안한다. 짧은 효과음은 mono를 기본으로 제작하고, 넓은 결과음/환경음은 필요할 때 stereo로 제작한다. 원본은 과한 리미팅 없이 여유를 두고 Unity에서 재생 볼륨을 맞춘다.
- 청각 우선순위는 코어 피해/결과 → 플레이어 조작·마법 → 일반 전투 → 환경 순으로 제안한다. 현재 매니저는 BGM/SFX/UI 채널만 구분하므로 SFX 안의 중요도별 재생 공간 보장은 후속 구현 사항이다.
- 변주 선택과 동일 이벤트 연속 재생 억제는 화면/사운드 계층에서 처리한다. 전투의 난수·타이밍·결과에는 영향을 주지 않는다. 현재 매니저에는 변주 자동 선택이나 이벤트별 쿨다운은 아직 없다.
- 동일 이벤트에 여러 클립을 쓰면 클립별 한도뿐 아니라 이벤트 전체의 동시 재생 한도도 필요하다. 현재 타격음의 클립별6개 제한만으로 변주 그룹 전체가6개로 제한되지는 않는다.
