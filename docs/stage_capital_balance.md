## 구조적 문제: 2진영 웨이브는 자주 만나지 않는다

경로가 두 묶음으로 갈리고, 두 묶음은 코어 바로 앞(14행, x 10~18)에서만 합쳐진다.

| 묶음 | 스폰 | 코어로 오는 길 |
| --- | --- | --- |
| 북쪽 | 고블린 1, 야수 0, 용족 0 | x=14 세로 통로로 내려온다 |
| 남·동쪽 | 고블린 0, 언데드, 야수 1, 용족 1 | 동쪽에서 14행으로 들어온다 |

경로가 26~41칸으로 길어서 진영 사이 속도 차이가 도착 시간 차이로 크게 벌어진다.
- 야수(속도 2.3~2.7)는 고블린(1.7)·언데드(1.1~1.6)보다 한참 먼저 지나간다.
- 코어도 시야를 막아서, 코어 앞에서 합쳐져도 서로 보기 전에 코어에 닿는다.

조합별로 시험한 결과다(벽 없음과 무작위 벽 후보 10~20개 중 최선).

| 2진영 조합 | 교전 | 판단 |
| --- | --- | --- |
| 고블린 + 야수 | 4개 스폰 조합 중 3개에서 교전 없음 | 2진영 웨이브에서 뺐다 |
| 언데드 + 용족 | 2개 중 2개 교전 없음 | 뺐다 |
| 언데드 + 야수 | 2개 중 2개 교전 없음 | 뺐다 |
| 고블린 + 언데드 | 고블린 1번 스폰 (34,22)에서 약함 | 사용 |
| 야수 + 용족 | 4개 중 1개 교전 없음 | 사용 |
| 고블린 + 용족 | 4개 중 2개 교전 없음 | 사용(약함) |

코어 동쪽 진입로를 막는 배치((11,13), (11,14))와 북쪽 통로를 막는 배치((14,16), (15,16))를 직접 시험했지만 교전은 생기지 않았다.

3·4진영 웨이브는 거의 모든 조합에서 교전이 일어난다.

**권장**: 맵 중간에서 남·동쪽 묶음과 북쪽 묶음이 만나도록 길목을 추가한다. 또는 빠른 야수의 경로가 길어지도록 고정 벽을 둔다. 길목을 바꾸면 이 문서의 결과는 다시 돌려야 한다.

## 다음 테스트에서 볼 것

- **길목 보강**: 2진영 웨이브의 교전 부족은 편성으로 풀 수 없다. 길목을 고친 뒤 W1~W5를 다시 돌린다.
- **고블린은 다진영 웨이브에서 거의 항상 전멸한다.** 머릿수가 많아 모든 진영과 부딪히기 때문이다.
- 의도한 "한쪽 10% 우세"는 이 맵에서는 스폰 조합에 따라 크게 흔들려 맞추지 못했다.
