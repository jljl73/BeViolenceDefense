# 다이얼로그 모음집

게임에 들어간 모든 대사를 화면 흐름 순서로 모았다. 문구 원본은 `ProjectBeViolenceDefense/Assets/Resources/GameText.ko.json`이고,
스테이지 대사는 `Tools/_out/dialogue_data.py`(작업용, git 제외)에서 함께 만든다. 대사를 고칠 때는 문구 테이블의 `text`만 바꾸면 된다.

- 화자 이름: 노아(`speaker.noah`), 다크엘프(`speaker.dark_elf`), 리치(`speaker.lich`), 하얀 늑대(`speaker.wolf_girl`), 마갑기사(`speaker.dark_knight`), 재앙룡(`speaker.dragon`)
- 스테이지 대사는 **입장 직후(전투 전)** 와 **승리 직후(결과 창 전)** 에 대화창으로 나온다. 같은 실행에서 다시 도전하면 입장 대사는 건너뛴다.
- 표정 표기: 노아는 대화 초상 8종, 정예는 기본/당황 2종(마갑기사·재앙룡은 기본만).

### 안내·경고

| 상황 | 첫 줄 | 둘째 줄 | 키 |
| --- | --- | --- | --- |
| 벽을 다 씀 | 벽이 다 떨어졌어요! | 벽을 하나 치우면 다시 놓을 수 있어요 | `hint.no_walls.*` |
| 길을 다 막음 | 길을 다 막으면 안 돼요! | 모든 출발 지점에서 성까지 길이 남아 있어야 해요 | `hint.keep_routes.*` |
| 이미 쓰는 칸 | 거긴 이미 뭔가 있어요! | 빈 칸을 골라 주세요 | `hint.cell_occupied.*` |
| 도발 대상 선택 | 누구를 도발할까요? | 도발할 유닛을 눌러 주세요 | `hint.pick_taunt_target.*` |
| 설정(창이 없는 씬) | 설정은 아직 준비 중이에요… | 조금만 기다려 주세요! | `hint.settings_pending.*` |
| 웨이브 정리 | 막아냈어요! | 다음 전투 전에 벽을 다시 놓아 보세요 | `hint.wave_cleared.*` |
| 스킬 사용 불가 | 앗, 지금은 안 돼요! | (사유) | `hint.cast_blocked.title` |
| 스킬 대상 없음 | 어라, 아무도 없어요… | (결과) | `hint.cast_missed.title` |
