# 웨이브 편집기

실제 데이터 형식은 `StageWaves` ScriptableObject다. 기존 에셋과 `StageData.waves` 참조를 그대로 사용한다.

## 열기

- Unity 메뉴 **Tools → Stage Waves Editor**.
- Project 창의 StageWaves 에셋을 더블클릭하거나 Inspector의 **웨이브 편집기 열기**.
- **Tools → Stage Editor**에서 웨이브를 연결한 뒤 **웨이브 편집기 열기**.
- Stage Editor에서 웨이브가 없으면 **웨이브 만들기… → 새로 만들기**. 새 에셋을 만들고 해당 StageData에 연결한다.

## 편집 흐름

1. 상단에서 편집할 에셋과 **유닛 카탈로그**를 확인한다. 기본값은 `Assets/04_Data/03_Balance/EnemyCatalog.asset`이다. 이 필드는 편집·검사용이며 게임에서 사용할 카탈로그는 씬의 `VoxelDefensePrototype`에 따로 연결되어 있다.
2. 왼쪽에서 웨이브를 선택한다. **+ 웨이브**, 복제, 삭제, ↑/↓ 또는 손잡이 드래그로 편성을 구성한다. 새 웨이브에는 고블린·언데드의 빈 후보 그룹이 하나씩 들어간다.
3. 오른쪽에서 팩션과 후보 그룹을 편집한다. 웨이브의 팩션은 2~4개이고 중복 선택할 수 없다. 기존 데이터의 잘못된 팩션과 중복은 검사 결과에 표시한다. 팩션을 바꾸더라도 기존 유닛을 자동으로 교체하지 않는다.
4. **+ 유닛**을 누르고 선택 메뉴에서 이름 또는 ID로 검색한다. 선택한 팩션의 유닛만 표시한다. 수량은 0 이상이며 **0명은 출전하지 않는다**. 행의 +는 복제, ×는 삭제다. 손잡이 드래그 또는 ↑/↓로 실제 출전 순서를 바꾼다.
5. 후보 그룹을 복제하면 같은 유닛 구성을 가진 독립적인 후보가 생긴다. 메모·유닛·수량을 바꿔 변형을 만든다.
6. 하단 **편성 검사**를 펼쳐 문제를 확인한다. **이동**으로 해당 웨이브를 선택한다. 필요하면 **스폰 검사**에 StageData를 넣어 해당 팩션의 스폰 유무도 확인한다. 이 필드는 StageData의 웨이브 연결을 바꾸지 않는다.
7. **저장** 또는 **Ctrl+S**로 현재 웨이브 에셋을 저장한다. 편집은 즉시 메모리에 반영되고 저장 전까지 하단에 변경 표시가 나온다. **Ctrl+Z / Ctrl+Y**로 되돌리기·다시 실행이 가능하다.

## 숫자 읽기

- 준비 단계마다 **팩션별 후보 그룹 하나만** 균등 확률로 뽑는다. 후보 2개면 각 50%다. 그룹을 복제하면 각 후보의 선택 확률도 바뀐다.
- 웨이브 총병력은 팩션별 후보의 최소·최대 병력을 합친 **가능한 출전 범위**다. 후보 전부를 합한 값이 아니다. 예를 들어 고블린 후보가 6명/10명, 언데드 후보가 4명이면 총병력은 10~14명이다.
- 범위는 편성표에 적힌 수량 기준이다. 잘못된 유닛 ID나 스폰 누락이 있으면 실제 출전 수와 다를 수 있으므로 검사 결과도 확인한다.
- 빈 후보도 무작위 선택 대상이다. 빈 후보·0 이하 수량·소속 불일치·스폰 누락은 경고, 구조 오류·알 수 없는 유닛·중복 카탈로그 ID는 오류로 표시한다.
- 검사 결과는 편집을 강제 수정하거나 저장을 막지 않는다. 카탈로그가 없으면 유닛 ID와 소속 검사는 미완료로 표시한다.

Play Mode 중에는 편성 편집이 잠긴다. 전투 중 런타임을 바꾸는 도구가 아니다. 원본 필드 확인이 필요하면 Inspector의 **원본 데이터 (고급)**을 펼친다.

## UI 참고

[2D Tower Defense Maker — Wave Timeline](https://hyunter777.github.io/2d-tower-defense-maker/editor-tools/#wave-timeline)의 웨이브 목록·요약, 선택 항목 상세 편집, 복제·재정렬, 검증 문제에서 편집 위치로 이동하는 흐름을 참고했다. 코드나 에셋을 가져오지는 않았다. 이 프로젝트에는 웨이브별 시작 지연·스폰 간격 데이터가 없으므로 시간축 대신 팩션별 후보 카드와 출전 순서 표를 사용한다.

색상 강조는 `UIPalette`의 선택·텍스트 역할 토큰을, 팩션 표식은 기존 `StageData.FactionColors`를 사용한다. 기존 Editor 도구와 동일한 IMGUI로 구현했고 추가 패키지가 필요하지 않다.
