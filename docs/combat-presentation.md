# 피격·사망 표현

`DefenseBoardView`가 살아 있는 전투 유닛과 사망 후 남은 화면 모델을 분리해 관리한다. 전투 사망 판정·유닛 목록 제거는 즉시 처리되며, 보이는 모델만 짧게 남는다. 피해량·충돌 반경·이동 좌표·전투 틱은 변경하지 않는다.

## 사망

- Animator에 `Base Layer.Death`가 있으면 해당 클립을 재생한다. 현재 EnemyCatalog의16종 중14종이 해당한다.
- `goblin-grunt-1500`, `goblin-grunt`는 해당 상태가 없으므로 Animator를 멈추고 몸을 뒤로 넘어뜨리는 대체 동작을 사용한다. 별도의 사망 클립을 제작한 것은 아니다.
- 클립을0.6~1.25초 범위로 재생하고0.12초 정지한 뒤0.3초 동안 사라진다. 대체 동작은0.48초다. 남은 모델은 투명해지면서 조금 가라앉고 축소된다.
- 진영 링·버프 표식·이동속도 잔상·조준용 재질은 제거한다. 코어 도달은 기존 코어 타격/퇴장 연출을 사용한다.
- 동시 사망 모델은 최대40개다. 초과하면 가장 오래된 모델부터 정리한다.
- 사망 포즈는 Animator 자동 시간 대신 호출부의 `BattleClock.DeltaTime`으로 직접 샘플링한다. 전투 배속·슬로우에 따라 재생되며 델타0에서는 멈춘다.

## 피격

- 기존 공격 애니메이션의 타격 지점에서 섬광·타격음과 함께 대상 모델을 잠깐 밝히고 뒤로 젖힌다.
- 화면 모델의 자식 `Body Reaction`만 변형한다. 실제 유닛 위치와 진영 링은 움직이지 않는다.
- 기본 반동은 최대0.065칸 이동·9° 기울기·작은 눌림이며0.16초 안에 복원된다. 공격 버프는1.2배, 방어 버프는0.55배 반동이다.
- 대상별 재반응 간격0.2초로 여러 유닛에게 맞을 때 계속 하얗게 굳는 현상을 줄인다. 공격 애니메이션 상태는 끊지 않는다.
- 타격 이펙트는 섬광0.065초·고리0.15초·파편 포함 전체0.22초. 일반 명중 크기는0.85배, 공격 버프 명중은1.12배다.
- 피격/사망 설정은 `Assets/02_Scripts/05_World/DefenseBoardView.cs`, 섬광·파편 설정은 `Assets/02_Scripts/00_Core/Effects/HitEffect.cs`의 상수에서 조정한다.

## 확인

Unity Play Mode에서 카탈로그16종의 사망 상태 선택, 대체 동작, 모델 정리, 동시 모델 제한, 델타0 정지, 코어 도달 구분을 확인했다. 피격 콜백에서 실제 타격음 호출·몸의 반동·섬광을 확인하고, 좌표/체력/루트 위치가 변하지 않는 것을 검사했다. 확대 캡처로 쓰러지는 자세와 사라지는 과정을 확인했다.

실제 단풍(Stage2) 스테이지에서 벽 `(0,4), (1,4), (15,4), (16,4)`로 교전을 유도한2배속 전투도 확인했다.2384틱 후 준비 단계로 정상 복귀했고, 전투 사망8회와 피격 반응이 관찰됐다. 벽 없는 첫 웨이브는 교전 없이 지나가므로 피드백 검증 배치로 사용하지 않았다.

## 스킬 범위 섬광

- 성공한 시전의 실제 범위를 순간적으로 밝히는 섬광, 확산 고리, 뒤따르는 얇은 고리, 12방향 빛줄기를 추가했다. 기존 유닛 적용 플래시·버프 표식·테두리 원은 유지한다.
- 공격력/회복/이동속도/방어막/도발 모두 `UIPalette`의 산호색/연두색/하늘색/보라색/분홍색을 사용한다.
- 첫 섬광은 0.12초, 면의 잔광은 0.24초, 전체 효과는 0.55초다. 실제 스킬 반경에 맞춰 확산하고 가장자리 빛 번짐만 반경의 최대 8%까지 뻗는다. 유닛과 벽의 깊이를 유지하며 바닥 위에 가산 합성한다.
- `SpellEffects.Advance`로 전달받은 `BattleClock.DeltaTime`만 사용한다. 셰이더는 `_Time`을 읽지 않는다. 동시에 재생하는 범위 섬광은 최대 16개이며 렌더러를 재사용하고 보드 종료 시 메시·재질을 해제한다.
- 구현: `Assets/02_Scripts/00_Core/Effects/SpellEffects.cs`, `Assets/Resources/SpellAreaBurst.shader`. 셰이더를 Resources에 넣어 런타임 로드와 빌드 포함을 보장한다.
- Unity 6000.3.28f1 Play Mode에서 실제 시전 연결, 5색 렌더 캡처, 정지, 범위 배율, 만료, 연속 시전 제한, 정리를 확인했다. [5색 미리보기](../ai-use/evidence/20261119-spell-flash/preview.gif).

## 유닛별 버프 낙뢰

- 실제 스킬 적용 대상마다 위에서 꺾인 빛줄기가 내려온다. 공격력·회복·이동속도·방어막은 모든 수신자, 도발은 거대화하는 첫 수신자에게만 표시한다.
- 스킬 색상의 부드러운 광채와 흰 중심선을 겹친다. 약 0.065초에 유닛에 도달하면 십자 섬광이 생기고, 전체는 0.38초 안에 사라진다. 기존 범위 섬광·몸 색상 플래시·버프 표식은 유지한다.
- 화면 유닛의 위치를 따라가고 대상 화면 오브젝트가 사라지면 즉시 정리한다. `BattleClock.DeltaTime`을 `SpellEffects.Advance`에서 받아 정지·슬로우·배속에 연동한다. 전투 모델은 수정하지 않는다.
- 빛줄기 높이는 `max(18, 32 × 유닛 축척)`으로, 초기 구현보다 10배 높여 화면 위쪽까지 길게 이어지게 했다. 축소된 유닛도 보드 기준 최소 18칸 위에서 내려온다. 꺾임은 SpawnOrder로 구분하고 전투 난수는 사용하지 않는다. 동시에 최대 128개를 재사용하며 보드 종료 시 재질과 화면 오브젝트를 해제한다.
- 구현: `Assets/02_Scripts/00_Core/Effects/BuffLightning.cs`, `SpellEffects.cs`, `Assets/Resources/BuffLightning.shader`. `DefenseBoardView.PlayAreaSpell`의 실제 수신자 목록에 연결했다.
- 실제 GameScene Play Mode에서 시전 큐 연결·3유닛 동시 적용·5색·도발 대상 구분·델타 0·이동 추종·대상 제거·만료·풀 제한·해제·셰이더 컴파일을 확인했다. [낙뢰 미리보기](../ai-use/evidence/20261119-buff-lightning/preview.gif).
