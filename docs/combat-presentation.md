# 피격·사망 표현

`DefenseBoardView`가 살아 있는 전투 유닛과 사망 후 남은 화면 모델을 분리해 관리한다. 전투 사망 판정·유닛 목록 제거는 즉시 처리되며, 보이는 모델만 짧게 남는다. 피해량·충돌 반경·이동 좌표·전투 틱은 변경하지 않는다.

## 사망

- Animator에 `Base Layer.Death`가 있으면 해당 클립을 재생한다. 현재 EnemyCatalog의16종 중14종이 해당한다.
- `goblin-grunt-1500`, `goblin-grunt`는 해당 상태가 없으므로 Animator를 멈추고 몸을 뒤로 넘어뜨리는 대체 동작을 사용한다. 별도의 사망 클립을 제작한 것은 아니다.
- 클립을0.6~1.25초 범위로 재생하고0.12초 정지한 뒤0.3초 동안 사라진다. 대체 동작은0.48초다. 남은 모델은 투명해지면서 조금 가라앉고 축소된다.
- 진영 링·버프 오라·이동속도 잔상·조준용 재질은 제거한다. 코어 도달은 기존 코어 타격/퇴장 연출을 사용한다.
- 동시 사망 모델은 최대40개다. 초과하면 가장 오래된 모델부터 정리한다.
- 사망 포즈는 Animator 자동 시간 대신 호출부의 `BattleClock.DeltaTime`으로 직접 샘플링한다. 전투 배속·슬로우에 따라 재생되며 델타0에서는 멈춘다.

## 피격

- 기존 공격 애니메이션의 타격 지점에서 섬광·타격음과 함께 대상 모델을 잠깐 밝히고 뒤로 젖힌다.
- 화면 모델의 자식 `Body Reaction`만 변형한다. 실제 유닛 위치와 진영 링은 움직이지 않는다.
- 기본 반동은 최대0.065칸 이동·9° 기울기·작은 눌림이며0.16초 안에 복원된다. 공격 버프는1.2배, 방어 버프는0.55배 반동이다.
- 대상별 재반응 간격0.2초로 여러 유닛에게 맞을 때 계속 하얗게 굳는 현상을 줄인다. 공격 애니메이션 상태는 끊지 않는다.
- 타격 이펙트는 섬광0.065초·고리0.15초·파편 포함 전체0.22초. 일반 명중 크기는0.85배, 공격 버프 명중은1.12배다.
- 피격/사망 설정은 `Assets/02_Scripts/05_World/DefenseBoardView.cs`, 섬광·파편 설정은 `Assets/02_Scripts/00_Core/Effects/HitEffect.cs`의 상수에서 조정한다.

## 확인

Unity Play Mode에서 카탈로그16종의 사망 상태 선택, 대체 동작, 모델 정리, 동시 모델 제한, 델타0 정지, 코어 도달 구분을 확인했다. 피격 콜백에서 실제 타격음 호출·몸의 반동·섬광을 확인하고, 좌표/체력/루트 위치가 변하지 않는 것을 검사했다. 확대 캡처로 쓰러지는 자세와 사라지는 과정을 확인했다.

실제 단풍(Stage2) 스테이지에서 벽 `(0,4), (1,4), (15,4), (16,4)`로 교전을 유도한2배속 전투도 확인했다.2384틱 후 준비 단계로 정상 복귀했고, 전투 사망8회와 피격 반응이 관찰됐다. 벽 없는 첫 웨이브는 교전 없이 지나가므로 피드백 검증 배치로 사용하지 않았다.

## 스킬 범위 섬광

- 성공한 시전의 실제 범위를 순간적으로 밝히는 섬광, 확산 고리, 뒤따르는 얇은 고리, 12방향 빛줄기를 추가했다. 유닛 적용 플래시·테두리 원과 함께 재생한다.
- 공격력/회복/이동속도/방어막/도발 모두 `UIPalette`의 산호색/연두색/하늘색/보라색/분홍색을 사용한다.
- 첫 섬광은 0.12초, 면의 잔광은 0.24초, 전체 효과는 0.55초다. 실제 스킬 반경에 맞춰 확산하고 가장자리 빛 번짐만 반경의 최대 8%까지 뻗는다. 유닛과 벽의 깊이를 유지하며 바닥 위에 가산 합성한다.
- `SpellEffects.Advance`로 전달받은 `BattleClock.DeltaTime`만 사용한다. 셰이더는 `_Time`을 읽지 않는다. 동시에 재생하는 범위 섬광은 최대 16개이며 렌더러를 재사용하고 보드 종료 시 메시·재질을 해제한다.
- 구현: `Assets/02_Scripts/00_Core/Effects/SpellEffects.cs`, `Assets/Resources/SpellAreaBurst.shader`. 셰이더를 Resources에 넣어 런타임 로드와 빌드 포함을 보장한다.
- Unity 6000.3.28f1 Play Mode에서 실제 시전 연결, 5색 렌더 캡처, 정지, 범위 배율, 만료, 연속 시전 제한, 정리를 확인했다. [5색 미리보기](../ai-use/evidence/20261119-spell-flash/preview.gif).

## 유닛별 버프 낙뢰

- 실제 스킬 적용 대상마다 위에서 꺾인 빛줄기가 내려온다. 공격력·회복·이동속도·방어막은 모든 수신자, 도발은 거대화하는 첫 수신자에게만 표시한다.
- 스킬 색상의 부드러운 광채와 흰 중심선을 겹친다. 약 0.065초에 유닛에 도달하면 십자 섬광이 생기고, 전체는 0.38초 안에 사라진다. 범위 섬광·몸 색상 플래시·지속 오라와 함께 재생한다.
- 화면 유닛의 위치를 따라가고 대상 화면 오브젝트가 사라지면 즉시 정리한다. `BattleClock.DeltaTime`을 `SpellEffects.Advance`에서 받아 정지·슬로우·배속에 연동한다. 전투 모델은 수정하지 않는다.
- 빛줄기 높이는 `max(18, 32 × 유닛 축척)`으로, 초기 구현보다 10배 높여 화면 위쪽까지 길게 이어지게 했다. 축소된 유닛도 보드 기준 최소 18칸 위에서 내려온다. 꺾임은 SpawnOrder로 구분하고 전투 난수는 사용하지 않는다. 동시에 최대 128개를 재사용하며 보드 종료 시 재질과 화면 오브젝트를 해제한다.
- 구현: `Assets/02_Scripts/00_Core/Effects/BuffLightning.cs`, `SpellEffects.cs`, `Assets/Resources/BuffLightning.shader`. `DefenseBoardView.PlayAreaSpell`의 실제 수신자 목록에 연결했다.
- 실제 GameScene Play Mode에서 시전 큐 연결·3유닛 동시 적용·5색·도발 대상 구분·델타 0·이동 추종·대상 제거·만료·풀 제한·해제·셰이더 컴파일을 확인했다. [낙뢰 미리보기](../ai-use/evidence/20261119-buff-lightning/preview.gif).


## 체력바와 지속 버프 상태

- `UnitStatusMarker`가 유닛별 체력 잔상 상태를 유지한다. 48×8 채움, 52×12 어두운 외곽, 피격 순간 밝아짐, 피해 잔상(0.1초 유지 후 감소), 체력 25% 이하의 느린 테두리 맥동을 적용한다. 진영색은 유지한다.
- 부상·회복 직후·교전 대상 존재·지속 버프 중 하나에 해당하면 표시한다. 체력이 가득 차도 버프 상태가 보인다. 제거된 유닛의 UI는 반환해 재사용한다.
- 아이콘/중첩이 모델을 덮지 않도록 체력바 중심을 머리 위 28 UI 단위에 둔다. 그 아래 아이콘 7×7, 타이머 12×12, 숫자 8px(2중첩 이상, 최대 표기 9+)의 한 줄만 표시한다. 슬롯은 활성 상태만 최대 4개, 각 12 단위 간격이다.
- 숫자와 그림자까지 포함한 영역이 화면상 유닛 몸의 보수적 추정 사각형이나 다른 체력바/버프 행과 겹치면 아이콘 행을 숨긴다. 몸 오라는 계속 표시한다. 모든 상태 UI의 raycast를 꺼서 보드 조작을 막지 않는다.
- 공격력/이동속도는 다음 중첩 만료까지, 방어막/도발은 효과 종료까지 원형 타이머가 줄어든다. 마지막 1초에는 약하게 맥동한다. 회복은 순간 효과이므로 지속 아이콘을 만들지 않는다.
- `UnitBuffAura`는 유닛 몸의 렌더 bounds를 따라 상태를 갱신한다. 공격력·방어막은 공유 원기둥 메시, 이동속도는 경로를 따라 휘는 공유 띠 메시, 나머지 상태는 공유 평면 메시/재질로 그린다. 공격력은 몸통 가까이 차오르는 산호색 열기와 공격 순간 맥동, 이동속도는 발 주변에서 지나온 경로를 따라 이어지고 빛이 뒤로 흐르는 잔광, 방어막은 몸보다 여유 있게 넓은 보라색 원기둥 보호막·피격 발광, 도발은 분홍 입자 소용돌이, 회복은 잠깐 솟아오르는 연두색 입자다. 기존 발밑 사각 표식은 제거했다.
- 몸 오라에는 `BattleClock.DeltaTime`을 전달하며 셰이더는 `_Time`을 사용하지 않는다. 종료 시 약 0.17초 안에 잦아들고 사망/코어 도달 즉시 숨긴다. 체력 UI의 잔상과 테두리는 UI 실시간을 사용한다.
- 실제 GameScene에서 체력 잔상, 저체력 테두리, 만피 버프 표시, 오라 정지/만료, 여러 버프 조합, 밀집 시 아이콘 숨김, 사망 후 반환, 입력 비차단과 셰이더 컴파일을 검증했다.


### 입자 밀도 보강 — 중간 단계

- 기존 왕관·마름모·원형 윤곽·꺾쇠·십자 도형을 지속 오라에서 제거했다. 입자마다 크기·밝기·생성 시점이 달라지고, 흔들리는 흐름과 두 겹의 입자층으로 밀도를 만든다. 격자처럼 줄지어 보이지 않도록 위치를 흔들고 일부 입자는 생략한다.
- Unity ParticleSystem을 추가하는 대신 기존 공유 메시의 셰이더에서 입자를 그린다. 활성 버프만 계산하며 가까운 네 셀을 샘플링한다. 개별 입자 GameObject나 텍스처를 생성하지 않는다.
- 오라 크기는 카메라에 투영한 몸 bounds를 사용한다. 기존 월드 높이 기준보다 몸 가까이 모으고 얼굴·몸 중심은 비워 둔다. 여러 버프가 겹칠 때 최대 발광을 제한한다.
- `BattleClock` 시간·피격 발광·만료 처리와 작은 상태 UI는 유지한다. Unity Play Mode에서 실제 렌더, 정지/만료, 밀집 UI 억제 및 셰이더 컴파일을 다시 확인했다.


### 부드러운 원기둥 방어막

- 몸을 따라가는 외곽선에서, 몸과 여유를 두고 감싸는 반투명 보라색 원기둥으로 변경했다. 사용자가 이 형태를 채택했으며 공격력 오라는 아래 별도 표현을 사용한다.
- `UnitShieldSurface`는 원본 모델을 복제하지 않고 공유 64면 원기둥 메시를 사용한다. 높이는 몸 bounds의 1.25배, 반지름은 몸 높이의 0.38배와 수평 최대 반경의 1.18배 중 큰 값이다. 크기와 위치는 몸의 bounds를 따라 갱신한다.
- 뚜껑이나 테두리 선을 만들지 않고, 위아래 끝과 옆 실루엣을 알파로 부드럽게 소거한다. 넓은 보라색 빛이 막 안에서 천천히 위로 흐르며 캐릭터의 모습이 비친다.
- 피격 방향에서 넓게 빛이 번진다. 기존 피격 시간과 전달된 `BattleClock.DeltaTime`만 사용하며, 정지·만료·사망 숨김을 유지한다.
- 공유 메시와 재질은 보드가 소유하고 해제한다. 표시 Renderer는 유닛 루트의 자식이다. 원본 재질, 체력바·아이콘·중첩 표시는 변경하지 않았다.
- Unity 6000.3.28f1 Play Mode에서 카탈로그 20종의 크기 여유·위치·이동·거대화, 원본 재질 보존, 정지·만료·사망 숨김, 피격 값과 셰이더 컴파일을 확인했다. 실제 렌더 증거: `ai-use/evidence/20261119-shield-cylinder/`.

### 공격력 — 몸통에 차오르는 산호색 열기

- `UnitAttackAura`는 방어막 메시를 공유하되 반지름을 방어막의 76%, 높이를 몸 bounds의 100%로 설정해 안쪽 몸통 주변에 머문다. 얼굴 쪽과 발밑, 측면 경계는 부드럽게 사라진다.
- `UIPalette.Attack` 색상을 바탕으로 넓고 연결된 빛이 위로 흐른다. 기존 공격력 불티 계산은 제거했으며 파편·개별 입자·단단한 테두리를 만들지 않는다.
- 공격 시작의 `EnemyUnit.AttackFlash`를 읽어 0.14초 동안 발광을 강화한다. 별도 전투 타이머를 추가하지 않고, 흐름은 전달된 `BattleClock.DeltaTime`으로만 진행한다.
- 중첩 수에 따라 메시나 크기를 늘리지 않는다. 방어막보다 안쪽에 산호색을 얇게 겹쳐, 바깥 보라색 막과 구분한다. 공유 재질은 보드의 해제 목록에 등록한다.
- 공격력에 이어 아래 이동속도 표현까지 적용했다. 도발·회복의 새 콘셉트는 미적용이다. 상태 아이콘·체력바와 전투 규칙은 유지한다.
- Unity 6000.3.28f1 Play Mode에서 20종 유닛의 이동·거대화, 방어막 동시 표시·독립 만료, 중첩 시 크기 유지, 정지·공격 맥동·사망 숨김과 셰이더 컴파일을 확인했다. 실제 렌더: `ai-use/evidence/20261119-attack-heat/`.

### 이동속도 — 경로를 따라 흐르는 빛

- 몸을 감싸던 낮은 구체를 제거하고, 발 주변에서 뒤로 이어지는 두 갈래의 넓고 흐릿한 빛으로 변경했다. `UIPalette.MoveSpeed` 색상과 부드러운 양 끝·측면 경계를 사용한다. 입자와 LineRenderer는 사용하지 않는다.
- `UnitSpeedAura`가 실제 표시 위치 48개를 저장하고 거리 기준 16개 지점으로 잔광을 그린다. 회전하면 지나온 경로를 따라 휘며, 잔광 전체를 새 방향으로 회전시키지 않는다. 표시용 공유 메시 64정점/60삼각형과 재질은 보드가 소유한다.
- 정지 시 길이는 몸 높이의 42%, 이동 시 최대 165%다. 정지하면 약 0.2초 안에 짧아진다. 덩어리로 뭉치지 않고 짧은 빛의 흐름을 유지한다. 셰이더의 밝은 마디가 발에서 꼬리 방향으로 계속 흐른다.
- 빛은 몸 bounds 최저점보다 높이의 22% 위에 두어 바닥 교차를 줄인다. GPU에서 변형한 메시가 잘못 컬링되지 않도록 각 유닛의 경로와 폭으로 Renderer bounds를 갱신한다.
- 전달된 `BattleClock.DeltaTime`이 0이면 위상·이동 강도·경로 이력을 진행하지 않는다. 순간이동은 이력을 초기화한다. 만료·사망·코어 도달 시 독립적으로 숨긴다. 중첩별 메시를 추가하지 않는다.
- 공격력·방어막과 상태 UI는 유지한다. 범위는 이동속도까지이며 도발·회복은 기존 이펙트다.
