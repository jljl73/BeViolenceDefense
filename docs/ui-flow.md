# 프로토타입 UI 흐름

`GameScene`의 `UI Canvas`는 Screen Space - Overlay를 사용한다. Canvas Scaler의 설정은 Scale With Screen Size, 기준 해상도 1920×1080, Screen Match Mode Expand다. HUD는 화면 모서리에 앵커를 두고 팝업은 중앙에 배치한다. 배경은 화면 전체를 채운다.

- **게임 시작**에는 전체 화면 스테이지 선택을 연다. 흐린 스테이지 배경 위 왼쪽에 위아래로 천천히 떠 있는 주인공 그림과 대사 띠, 오른쪽에 위에서부터 해안가·황금 단풍 평원·설원·묘지·왕도 카드 5장이 있다. 카드는 클리어·현재·잠김 상태를 보이고, `입장`을 누르면 해당 스테이지 프리팹을 생성하고 준비 단계로 들어간다. 진행도마다 대사와 주인공 표정이 바뀐다. 진행도 저장은 아직 없어서 `StageSelectionPopup.unlockedStages`(기본 5, 모두 열림)로 임시 지정하며, 저장 기능은 `SetProgress`로 넘겨준다. 입장할 때는 타이틀 카드 연출(`StageTransition`, 약 2.7초)이 나온다. 금색·크림·자주색 사선 띠가 차례로 화면을 덮고, 왼쪽 사선 창에 스테이지 그림, 오른쪽에 `STAGE`·번호·리본 속 이름이 순서대로 나타난다. 타이틀이 자리를 잡은 뒤 덮인 동안 스테이지를 생성하고, 자주색 띠가 타이틀을 실은 채 왼쪽으로 빠지며 크림·금색 띠가 뒤따른다. 스테이지 그림은 `StageTransition.stageArt`에 번호 순서로 넣는다. 다시 하기로 씬이 새로 열릴 때는 덮인 상태에서 시작한다. 선택 전에는 보드와 전투를 생성하지 않으며 `Esc`로 선택 화면을 닫을 수 없다.
- **재시작**은 현재 선택한 스테이지를 유지한 채 전투와 배치 상태를 초기화한다. 앱의 새 실행/에디터의 새 Play 세션은 다시 선택 팝업에서 시작한다. [스테이지 프리팹 구조](stage-prefabs.md)를 참고한다.

- **HUD**는 배경 패널 없이 왼쪽 위에 코어 체력, 위쪽 중앙에 라운드와 현재 단계를 표시한다. 오른쪽 위에는 준비 중 남은 벽, 전투 중 배속을 표시한다. 조작 안내는 왼쪽 아래 `?`에서 볼 수 있고, 행동 결과는 잠시 알림으로 표시한다. 읽기 전용 요소는 포인터를 통과시키며, UI 버튼 위에서 누른 입력은 보드에 전달하지 않는다.
- 전투 중 상단 중앙의 `전장 체력` 막대는 전장에 있는 두 진영의 남은 체력 합을 각 진영의 보드 색으로 비교한다. 양옆 숫자는 생존 유닛 수다. 아직 스폰하지 않은 유닛은 집계에서 제외하며, 양쪽 모두 전장에 유닛이 없으면 막대는 비어 있다.
- **Popup**은 확인이나 다음 행동이 필요한 화면에 사용한다. `Popup` 레이어 바로 아래에 비활성 패널을 두고 `UIManager.ShowPopup`으로 연다. 열려 있는 패널을 다시 요청하면 기존 순서를 유지한다. 맨 위 패널만 표시하며, 닫으면 직전 패널을 복원한다. 버튼에서 `CloseTopPopup`을 호출할 수 있고 기본적으로 `Esc`도 맨 위 팝업을 닫는다.
- 팝업이 열린 동안 보드 클릭과 게임 단축키를 차단하고 전투 시뮬레이션은 계속 진행한다. 팝업 안의 조작은 Unity Input System의 UI 모듈에서 처리한다.
- 준비 중에는 재생 아이콘이나 `Space`로 전투를 시작한다. 전투 중 하단에 마나 게이지와 공격력·힐·이동속도·방어막·도발 버튼 5개가 표시된다. 아이콘 옆에는 단축키, 아래에는 마나 비용이 나온다. 사용 횟수 제한은 없다. 버튼에 마우스를 올리거나 키보드로 선택하면 스킬 효과와 사용 불가 이유를 볼 수 있다. 공격력 버프·힐·이동속도 버프는 각 버튼 또는 `1`·`2`·`3`으로 조준한 뒤 보드를 왼쪽 클릭해 시전하고, 오른쪽 클릭이나 `Esc`로 취소한다. 힐의 범위는 연두색 원으로 표시한다. 도발은 `5`로 조준한 뒤 유닛을 클릭해 시전한다. 조준 중 마우스 아래 유닛 둘레에 분홍색 도발 반경을 그리고, 그 유닛과 끌려올 유닛을 강조한다. 하단 안내에 끌려올 유닛 수가 나온다. 도발 반경은 고정이라 조준 중에도 휠로 카메라를 확대·축소한다. 도발 중인 유닛은 2배로 커진다.
- HUD 오른쪽 위의 `1x`와 `2x` 버튼은 선택한 전투 배속을 표시한다. 범위 조준 중에는 HUD에 `조준 중 · 0.1배속`가 표시되고 전투가 정상 속도의 0.1배로 진행된다. 시전하거나 조준을 취소하면 선택한 배속으로 돌아간다.
- 범위 조준 중 휠을 올려 반경을 늘리고 내리면 줄인다. 하단 조준 안내에 현재 반경, 마나 비용, 대상 수가 표시된다. 원 안의 유닛은 밝아지고 실제로 효과를 받을 대상에는 조준 원의 색을 더 강하게 입힌다. 조준을 끝내면 휠로 카메라를 확대하거나 축소할 수 있다.
- 유닛의 진영색 체력바는 부상 중이거나 회복 직후에만 머리 위에 표시한다. 활성 버프는 발밑의 짧은 색 표식으로 확인한다. 왼쪽 산호색은 공격력, 가운데 하늘색은 이동속도, 오른쪽 보라색은 방어막이다. 방어막은 6초간 받는 피해를 80% 줄이고, 재시전하면 지속시간을 갱신한다(감소율 중첩 없음).
- 전투 중에는 하단 중앙에 스킬 아이콘 5개를 배치한다. 마나 게이지와 현재량은 아이콘 아래 한 줄에 표시한다.
- 라운드를 정리하면 클리어 알림을 표시하고 바로 준비 HUD로 돌아온다. 카메라 이동·캐릭터 포즈·HUD 숨김 연출은 사용하지 않는다. 코어가 파괴되면 패배 팝업을 열며, 팝업의 다시 시작 버튼이나 `R`로 씬을 다시 시작한다.

## 화면 문구 관리

[한국어 텍스트 테이블](../ProjectBeViolenceDefense/Assets/Resources/GameText.ko.json)의 `text`를 수정하면 다음 플레이에서 반영된다. `key`는 씬·데이터·코드에서 참조하는 값이다. `{0}`, `{1:0.0}` 같은 자리는 웨이브 번호, 스킬 수치 등의 표시 위치이며 TMP 태그는 글자 스타일을 지정한다.

새 대사는 테이블에 키와 문구를 추가한 뒤 대화 흐름에 화자 키·대사 키·표정을 연결한다. 유닛과 스테이지의 표시 이름 키는 각 데이터 에셋에 연결한다.

## 캐주얼 HUD 아트 목록

| 적용 화면 | 리소스 | 원본 크기 |
| --- | --- | --- |
| 재시작 | `Button.png` 공용 버튼 | 128×64 |
| 패배 팝업 | `Panel.png` 공용 패널 | 64×64 |
| 준비·패배 | `Start.png`, `Restart.png` | 각 96×96 |
| 전투 | `AttackBuff.png`, `Heal.png`, `MoveSpeedBuff.png`, 방어 버프에는 `Wall.png` 재사용 | 각 96×96 |
| 상태와 자원 | `Core.png`, `Wall.png`, `Mana.png` | 각 96×96 |
| 빈 스킬 슬롯 | `Lock.png` | 64×64 |

투명 PNG는 `Assets/07_UI/01_Icons/Hud`에 둔다. 패배 팝업과 재시작 버튼은 Unity의 9-slice로 모서리 형태를 유지한다. 전투 시작과 재시작은 금색을 쓰고, 사용 가능한 스킬은 산호색·연두색·하늘색·보라색·분홍색 아이콘으로 구분한다. 도발 전용 아이콘이 없으면 `Enemy.png`에 도발 색을 입혀 쓴다. 사용할 수 없는 스킬은 흐리게 표시하고 조준 중인 스킬에는 `OutlineFocus` 원형 테두리를 표시한다.

## 색상 규칙

UI 색은 `Assets/02_Scripts/06_UI/UIPalette.cs`의 토큰만 사용한다. 코드에 색 값을 직접 쓰지 않으며, 색을 바꿀 때는 이 파일의 hex 값만 수정한다.

| 그룹 | 토큰 | 값 | 용도 |
| --- | --- | --- | --- |
| 배경·패널 | `Background` | `#17121F` | 화면 전체 배경 |
| | `Panel` | `#2A2030` | 기본 패널 |
| | `PanelRaised` | `#3B2D3D` | 패널 위에 올라오는 상위 패널 |
| | `PanelBrown` | `#5E3F3C` | 보상·경고·팝업 헤더 등 강조 패널 |
| | `Overlay` | `#17121F` 72% | 모달 뒤 화면 |
| | `BarTrack` | `#150F1A` | 게이지 빈 부분 |
| 외곽선 | `Outline` | `#7D6654` | 패널·버튼 기본 테두리 |
| | `OutlineStrong` | `#C9A77C` | 호버, 갈색 패널 테두리 |

| | `TextOnAccent` | `#2A2030` | 밝은 버튼 위 글자·아이콘 |

- 깊이는 `Background` → `Panel` → `PanelRaised` 순으로 밝아진다. 위에 올라오는 요소일수록 한 단계 밝은 면을 쓴다.
- 외곽선은 면보다 한 단계 밝게 쓰고, 선택·포커스에만 금색을 쓴다.
- 밝은 버튼 위 글자는 `TextOnAccent`, 어두운 면 위 글자는 `TextPrimary`나 `TextSecondary`를 쓴다.
- 버튼 아트는 흰색으로 만들어 코드에서 색을 입힌다. 패널 아트도 같은 방식으로 맞춘다.

후속 작업 후보는 벽 배치·철거 조작 아이콘과 팩션 표식이다.
