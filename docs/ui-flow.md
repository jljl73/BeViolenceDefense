# 프로토타입 UI 흐름

`GameScene`의 `UI Canvas`는 Screen Space - Overlay를 사용한다. Canvas Scaler의 설정은 Scale With Screen Size, 기준 해상도 1920×1080, Screen Match Mode Expand다. HUD는 화면 모서리에 앵커를 두고 팝업은 중앙에 배치한다. 배경은 화면 전체를 채운다.

- **HUD**는 깃발 옆에 라운드 번호, 보석 옆에 코어 체력, 벽이나 해골 옆에 배치·스폰 수를 표시한다. 조작 안내는 왼쪽 아래 `?`에서 볼 수 있고, 행동 결과는 잠시 알림으로 표시한다. 읽기 전용 요소는 포인터를 통과시키며, UI 버튼 위에서 누른 입력은 보드에 전달하지 않는다.
- **Popup**은 확인이나 다음 행동이 필요한 화면에 사용한다. `Popup` 레이어 바로 아래에 비활성 패널을 두고 `UIManager.ShowPopup`으로 연다. 열려 있는 패널을 다시 요청하면 기존 순서를 유지한다. 맨 위 패널만 표시하며, 닫으면 직전 패널을 복원한다. 버튼에서 `CloseTopPopup`을 호출할 수 있고 기본적으로 `Esc`도 맨 위 팝업을 닫는다.
- 팝업이 열린 동안 보드 클릭과 게임 단축키를 차단하고 전투 시뮬레이션은 계속 진행한다. 팝업 안의 조작은 Unity Input System의 UI 모듈에서 처리한다.
- 준비 중에는 재생 아이콘이나 `Space`로 전투를 시작한다. 전투 중 하단에 마나 게이지와 칼·하트·날개 달린 장화 버튼이 표시된다. 아이콘 옆에는 단축키, 아래에는 마나 비용과 남은 횟수(`×3` 형식)가 나온다. 버튼에 마우스를 올리거나 키보드로 선택하면 스킬 효과와 사용 불가 이유를 볼 수 있다. 공격력·이동속도 버프는 버튼 또는 `1`·`3`으로 조준한 뒤 보드를 왼쪽 클릭해 시전하고, 오른쪽 클릭이나 `Esc`로 취소한다. 힐은 적을 선택하고 하트 버튼이나 `2`로 시전한다.
- HUD 오른쪽 위의 `1x`와 `2x` 버튼은 선택한 전투 배속을 표시한다. 범위 조준 중에는 유닛의 이동을 멈춘다. 보드를 클릭하거나 조준을 취소하면 이동을 재개한다.
- 전투 중에는 하단에 개별 스킬 슬롯 6개가 한 줄로 놓인다. 앞의 3개는 현재 스킬이며 뒤의 3개는 자물쇠로 표시한다. 넓은 마나 게이지와 현재량은 슬롯 아래 줄에 표시한다.
- 라운드를 정리하면 준비 HUD로 돌아온다. 코어가 파괴되면 패배 팝업을 열며, 팝업의 Restart 버튼이나 `R`로 씬을 다시 시작한다.

## 캐주얼 HUD 아트 목록

| 적용 화면 | 리소스 | 원본 크기 |
| --- | --- | --- |
| 전투 시작, 스킬 3종, 1x·2x, 재시작 | `Button.png` 공용 버튼 | 128×64 |
| 라운드 상태, 배속, 액션 바, 패배 팝업 | `Panel.png` 공용 패널 | 64×64 |
| 준비·패배 | `Start.png`, `Restart.png` | 각 96×96 |
| 전투 | `AttackBuff.png`, `Heal.png`, `MoveSpeedBuff.png` | 각 96×96 |
| 상태와 자원 | `Round.png`, `Core.png`, `Wall.png`, `Enemy.png`, `Mana.png` | 각 96×96 |
| 빈 스킬 슬롯 | `Lock.png` | 64×64 |

투명 PNG는 `Assets/Art/Hud`에 둔다. 버튼과 패널은 Unity의 9-slice로 모서리 형태를 유지한다. 전투 시작과 재시작은 금색을 쓰고, 사용 가능한 스킬은 산호색·연두색·하늘색 아이콘으로 구분한다. 사용 불가와 미선택 상태는 `ButtonDisabled`, 조준과 선택은 `OutlineFocus`를 쓴다.

## 색상 규칙

UI 색은 `Assets/Scripts/UI/UIPalette.cs`의 토큰만 사용한다. 코드에 색 값을 직접 쓰지 않으며, 색을 바꿀 때는 이 파일의 hex 값만 수정한다.

| 그룹 | 토큰 | 값 | 용도 |
| --- | --- | --- | --- |
| 배경·패널 | `Background` | `#0B0D2B` | 화면 전체 배경 |
| | `Panel` | `#1D1A38` | 기본 패널 |
| | `PanelRaised` | `#32273F` | 패널 위에 올라오는 상위 패널 |
| | `PanelBrown` | `#583642` | 보상·경고·팝업 헤더 등 강조 패널 |
| | `Overlay` | `#0B0D2B` 72% | 모달 뒤 화면 |
| | `BarTrack` | `#120F26` | 게이지 빈 부분 |
| 외곽선 | `Outline` | `#4A3B5C` | 패널·버튼 기본 테두리 |
| | `OutlineStrong` | `#7A5A78` | 호버, 갈색 패널 테두리 |
| | `OutlineFocus` | `#FFD170` | 선택·포커스 |
| 텍스트 | `TextPrimary` | `#F3E9E2` | 본문, 제목 |
| | `TextSecondary` | `#B9A9BE` | 보조 설명, 비활성 버튼 글자 |
| | `TextDisabled` | `#6E6280` | 완전히 꺼진 항목 |
| | `TextOnAccent` | `#1D1A38` | 밝은 버튼 위 글자·아이콘 |
| 버튼 | `ButtonPrimary` | `#FFD170` | 전투 시작, 재시작 |
| | `ButtonSecondary` | `#4A3B5C` | 일반 행동 |
| | `ButtonDisabled` | `#3A3148` | 사용 불가, 미선택 |
| | `ButtonDanger` | `#E5484D` | 되돌릴 수 없는 행동 |
| 게임 의미 | `Mana` · `Attack` · `Heal` · `MoveSpeed` | `#64C4FF` · `#FFA588` · `#99F5A0` · `#66DAFF` | 해당 기능을 가리킬 때만 사용 |

- 깊이는 `Background` → `Panel` → `PanelRaised` 순으로 밝아진다. 위에 올라오는 요소일수록 한 단계 밝은 면을 쓴다.
- 외곽선은 면보다 한 단계 밝게 쓰고, 선택·포커스에만 금색을 쓴다.
- 밝은 버튼 위 글자는 `TextOnAccent`, 어두운 면 위 글자는 `TextPrimary`나 `TextSecondary`를 쓴다.
- 버튼 아트는 흰색으로 만들어 코드에서 색을 입힌다. 패널 아트도 같은 방식으로 맞춘다.

후속 작업 후보는 벽 배치·철거 조작 아이콘과 팩션 표식이다.
