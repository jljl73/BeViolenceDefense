- 목적 및 적용 위치: 더미 맵을 의도가 있는 레벨로 교체. `DefenseGrid.cs`, `VoxelDefensePrototype.cs`, `GameScene.unity`, `docs/level-stage1.md`, `docs/images/stage1_level_design.png`, `docs/prototype.md`, `docs/balance.md`, `BalanceSim/`
- 사용 방식: `DefenseGrid.FindRoutes`와 같은 규칙의 Python 도구로 지형 초안을 반복 수정하고, `BalanceSim`으로 웨이브별 벽 없음·플레이어 벽 조건을 비교했다. `DefenseGrid`가 고정 벽 목록을 받도록 바꾸고 프로토타입에 17×17 글자 맵(`boardLayout`)을 추가했다.
- 결과 및 확인 방법: 부분 성공 / Unity 자동 컴파일 오류 0건, `Assembly-CSharp.dll` 반영 확인. 씬 데이터 기준 시뮬레이션: W1 무승부 75%, W2 벽 없음 9마리 돌파 → 문 2개 막으면 1.9마리, W3 무승부 42%. Play Mode 미확인.
- 사람의 개입: 사용자가 3웨이브 레벨 디자인, 시각화, 의도 설명, 적용을 요청했다.
