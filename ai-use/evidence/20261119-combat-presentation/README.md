# 피격·사망 연출 확인

Unity6000.3.28f1, 복제 프로젝트 `/tmp/be-impact-validation`에서 실행했다. 전투 모델 코드는 수정하지 않았다.

- `CombatPresentationValidation.cs.txt`: 카탈로그 기반 모델로 만든 표시 전용 검증. 타격 콜백·모델 반동·섬광·좌표/체력 불변, 델타0 정지, 사망 모델 유지와 최종 제거, 카탈로그16종(Death14/대체2),40개 제한과 코어 도달 분리를 검사했다.
- `preview.gif`: 왼쪽 일반 고블린은 대체 쓰러짐, 오른쪽 좀비는 기존 Death 클립. 검증용 보드에서 통제한 연출이며 실제 전투 타임라인은 아니다.
- `CombatImpactBattleValidation.cs.txt`: 공통 GameScene에서 단풍(Stage2) 선택 후 벽4개로 두 진영의 교전을 유도해 실제2배속 전투를 진행했다.2384틱 후 Preparation, 사망8회, 화면 동시 사망 모델 최대2개, 피격 반응 관찰. `battle.gif`는 이 실행의 캡처다.
- `controlled-results.txt`, `battle-results.txt`: 완료 결과. 동작 검사와 렌더 캡처를 수행했으며 별도 신규 EditMode 테스트는 작성하지 않았다.
- 처음 실제 전투 검증에서는 팝업 초기화 전에 진행하는 러너 순서를 수정했다. 이후 벽 없는 Stage2 첫 웨이브는 교전 없이 종료되어, 교전용 벽 배치를 추가한 뒤 검사 완료했다. 이 과정에서 게임 규칙이나 Stage2 데이터를 수정하지 않았다.
- Unity SearchDatabase 에디터 시작 색인 예외가 관찰됐으나 게임 표시 연출 검사는 정상 완료했다.

피격 반응 재적용 간격0.2초는 코드상 제한이며, 이번 러너는 간격 경계값을 별도 단언하지 않았다. 모든 클립의 미술적 품질을 개별 청취/수작업 승인한 것은 아니며, 기본 고블린·좀비 확대 화면과 실제 전투 화면을 시각 확인했다.
