# 인지 확대 및 피격 반응 — 2026-11-19

## 적용

- 실제 EnemyCatalog 16종 인지 +0.8칸: 일반 근접 2.2→3.0, 사신/와이번 2.5→3.3, 원거리 3.5→4.3. 새 항목과 EnemyFaction 기본값 3.0. 공격 사거리·몸통 크기·교전 합류 4.5칸은 그대로다.
- QueueDamage에 공격자를 전달하고, 같은 틱의 모든 피해를 해결한 뒤 피격 대상의 타깃을 다시 계획한다. 진행 중인 공격은 공통 스냅샷으로 판정해 동시 사망을 유지한다.
- 피격자는 공격자를 4초 기억한다. 이 공격자는 평소 인지 거리 밖에서도 찾지만 벽에 가리거나 사망하면 추격 대상으로 선택하지 않는다. 같은 공격자의 추가 타격은 기억을 갱신한다. 방어력으로 피해가 0이 된 명중도 반응한다.
- 당장 때릴 수 있는 기존 상대는 유지한다. 그 외에는 처음 맞았을 때 공격자를 우선 검토하고, 빈 공격 자리·접근 가능 여부 및 기존 정체 재선정 규칙을 따른다. 매 타격마다 막힌 공격자에게 강제 복귀하지 않는다.
- 여러 공격자의 동시 명중은 기존에 기억한 공격자 우선, 없으면 거리와 SpawnOrder로 결정한다. 다른 공격자에게 계속 맞는다고 기존 기억을 무한 갱신하지 않는다.

## 실행 방식과 범위

원본 프로젝트가 열려 있어 `/tmp/be-retaliation-validation` 복사본에서 실행했다. `-batchmode -nographics -runTests -testPlatform EditMode`로 전체 테스트, 그래픽 사용 `-batchmode -executeMethod RetaliationPlayValidation.Run`으로 실제 씬 Play Mode를 수행했다. 진단 스크립트는 복사본에만 넣고, 복사본 게임 루프의 각 battle.Tick 직후 RetaliationTickTrace.Record를 호출했다. 원본 Flow/씬에는 계측 코드를 넣지 않았다.

Unity 검색 인덱서의 ArgumentOutOfRangeException이 1건 로그에 남았으나 컴파일/테스트/3웨이브 플레이는 성공했다. Windows 빌드, 모든 스테이지/편성의 밸런스는 이번 확인 범위가 아니다. 인지와 교전 우선순위 변화로 전투 결과가 달라질 수 있다. 화면/UI/경로 마커의 동시 작업은 이번 변경에서 제외했다.
