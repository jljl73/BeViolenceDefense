# 체력바·지속 버프 상태 검증

- Unity 6000.3.28f1 CLI, `/tmp/be-unit-status-validation` 복제본에서 GameScene Play Mode 실행. 최종 종료 코드 0.
- 스테이지 전환이 끝난 뒤 좀비 3개를 통제된 위치에 배치하고 서로 다른 체력·버프·중첩 상태를 적용했다. 실제 HUD와 보드 뷰를 사용했다. 일반 전투 스폰/진형을 측정한 장면은 아니다.
- `status.png`: 체력바, 작은 아이콘·중첩, 공격력+이동속도/방어막/도발의 지속 오라. `crowded.png`: 두 유닛을 겹친 검사에서 아이콘 행이 숨겨지는 화면. `preview.gif`는 실제 렌더의 유닛 영역을 자른 확대 미리보기.
- 48×8 체력 채움, 피해 잔상, 저체력 테두리, 만피 버프 상태의 체력바 노출, UI raycast 비활성, 8px 중첩 숫자, 델타 0 오라 정지, 이동/여러 버프 상태 갱신, 만료 후 오라/아이콘 숨김, 밀집 시 아이콘 행 숨김, 사망 유닛의 UI 반환을 확인했다.
- 유닛 몸 범위 추정은 화면의 머리/발 위치로 만들며 거대화 크기도 반영한다. 아이콘 겹침 검사에는 숫자와 그림자가 차지하는 범위도 포함한다. 극단적인 밀집/모든 모델의 실루엣 정합성까지 보장하는 정밀 픽셀 충돌 검사는 아니다.
- C# 및 UnitBuffAura 셰이더 컴파일 통과. 이번 수정 파일 5개의 최종 소스가 검증 복제본과 일치함을 확인했다.
- 첫 시각 캡처는 스테이지 전환에 가려져 검증 코드를 수정해 전환 완료 후 다시 촬영했다. 도중 다른 작업의 코어 HUD 의존 파일이 복제본에서 서로 다른 버전이라 한 차례 컴파일 실패했으나 최신 의존 파일을 맞춘 뒤 최종 컴파일·검증 통과. 시작 시 UnityEditor.Search.SearchDatabase 예외는 관찰됐다.
- 전투 로직은 이 작업에서 변경하지 않았으므로 EditMode 전체 회귀는 재실행하지 않았다. Windows 빌드, 실제 최대 군중 규모 성능, 모든 스테이지/줌 거리에서의 체감은 미확인.
