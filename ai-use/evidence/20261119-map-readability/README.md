# 맵별 바닥·화살표·유닛 가독성 비교

- 원본 프로젝트를 `/tmp/be-map-readability`로 복제하고 Unity 6000.3.28f1 CLI에서 현재 GameScene에 연결된 5개 스테이지를 차례로 실행했다. 실제 연결은 해안가·황금 단풍 평원·설원·묘지·왕도다. 과거 기본 스테이지 프리팹은 현재 목록에서 제외되어 있다.
- 각 스테이지의 기본 준비 화면과 실제 첫 웨이브를 고정 틱 600회(10초) 진행한 전투 화면을 촬영했다. 원본 기본 카메라 줌을 유지했다. 시간 HUD는 정상 Update를 정지한 검증 실행이므로 00:00으로 남을 수 있으며 전투 진행 시간은 틱 수가 기준이다.
- 별도 비교 컷은 카메라 각도 X55/Y315, 직교 크기 1.8, 1280×960, 같은 4종 모델·4색 진영 화살표·배치·크기로 통제했다. UI와 기존 전투 유닛·임시 효과·파티클을 숨겼다. 조명·그림자·후처리·테마·타일 텍스처는 각 맵의 설정 그대로다.
- 화살표는 실제 공유 메시·재질·진영색·단일 경로 폭을 사용했다. 유닛은 카탈로그의 goblin-grunt-1500 / zombie / bat / demon이다. 모델과 화살표는 검사용으로 배치했으며 실제 전투 중 배치라는 뜻은 아니다.
- `probe-normal`은 일반 타일, `probe-route`는 같은 위치의 바닥 재질을 실제 경로 강조 재질로 바꾼 비교 컷이다. 후자는 화면 영역의 바닥 전체를 바꾼 통제 실험이며 자연스러운 준비 경로 배치가 아니다. 실제 경로는 planning에서 확인한다.
- `comparison.png`: 일반 바닥 5개 비교. `route-comparison.png`: 일반/경로 강조 바닥 비교. `overviews.png`: 기본 준비/실제 전투 10초 화면. 합성은 크롭·일부 리사이즈·라벨만 적용했고 색 보정은 하지 않았다.
- `captures/*-meta.json`에 실제 맵 크기·기본 줌·통제 카메라·테마색·모델 정보를 기록했다. `source-hashes.txt`는 실제 촬영에 사용한 복제본 기준이다. 원본 게임의 코드·색·재질·씬은 이 작업에서 변경하지 않았다.
- 결과는 육안 가독성 비교이며 접근성 대비비나 사용자 테스트 점수가 아니다. 한 구역·첫 웨이브·정해진 4종 표본이며 모든 조명 구역/유닛/웨이브를 대표하지 않는다. Windows 렌더는 미확인이다.
