# 공격력 열기 오라 검증

- Unity 6000.3.28f1 CLI가 프로젝트 복제본 `/tmp/be-attack-heat-validation`에서 `AttackAuraValidation.Run`을 실행했다. 검증 코드는 복제본에만 추가했다.
- 실제 GameScene의 단풍 스테이지에서 기본/공격력/공격력+방어막 유닛을 배치했다. 화면을 확대하고 비교를 가리는 경로 화살표·배경 낙엽만 복제본에서 숨겼다. 원본 게임은 유지했다.
- `sustained.png`, `pulse.png`는 실제 URP 렌더 원본이다. `preview.gif`는 연속 프레임을 크롭하고 라벨만 추가했다. 캡처 중 모델의 타이머와 애니메이션을 일정 간격으로 진행했으며 두 버프 유닛이 화면 밖 유효 대상을 공격하도록 해 맥동을 확인했다.
- 카탈로그 20종의 공유 메시, 원본 재질, 이동·거대화 추적, 방어막보다 작은 범위, 공격 불티 비활성, 정지 시 위상과 맥동 유지, 독립 만료, 중첩 시 Renderer/상대 크기 유지, 사망 숨김, 공격 파라미터, 셰이더 컴파일을 검사했다.
- 결과와 알려진 검색 인덱스 시작 예외는 `results.txt`, 구현 해시는 `source-hashes.txt`에 있다. Windows 빌드와 대규모 버프 전투 성능은 확인하지 않았다.
