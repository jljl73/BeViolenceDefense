# 스킬 범위 섬광 검증

- Unity 6000.3.28f1 CLI의 별도 복제 프로젝트 `/tmp/be-spell-flash-validation`에서 GameScene Play Mode 실행. 종료 코드 0.
- 실제 스테이지 선택·전투 시작 후 방어막 명령을 큐에 넣어 범위 섬광이 1회 시작되는 것을 확인했다.
- 기존 `PlayAreaSpell`을 사용해 5개 스킬의 색상을 같은 위치/반경에서 재생하고 프레임을 캡처했다. `preview.gif`는 이를 나란히 배치한 확대 비교이며, 다섯 스킬을 실제로 한꺼번에 시전한 화면은 아니다.
- 표식/유닛 적용 효과 유지, 델타 0 정지, 반경 확대, 0.55초 만료, 50회 연속 요청 시 동시 섬광 16개 제한, 반환/해제, 셰이더 지원·컴파일 확인.
- C# 및 셰이더 컴파일 오류 없음. 시작 시 UnityEditor.Search.SearchDatabase 예외와 종료 시 Persistent allocation 9개 경고는 관찰됨. 같은 경고는 직전 방어막 검증 로그에도 있으며 이번 범위 섬광 렌더러/메시/재질 해제 검사는 통과했다.
- `SpellFlashValidation.cs.txt`는 검증 복제본에만 넣은 코드다. 이미지/GIF는 실제 Unity 렌더 캡처로 제작했다.
- 전투 모델은 이번 작업에서 수정하지 않아 EditMode 전체 회귀는 재실행하지 않았다. Windows 빌드와 다른 모든 스테이지에서의 가독성은 미확인.
