# 부드러운 원기둥 방어막 검증

- 실제 프로젝트 Assets/Packages/ProjectSettings/Library를 `/tmp/be-shield-cylinder-validation`에 복제해 Unity 6000.3.28f1 CLI에서 Play Mode 검증했다.
- `ShieldSurfaceValidation.cs.txt`: 복제본에만 넣은 검증 코드. GameScene에서 단풍 스테이지 전환 완료 후 동일 유닛 3개를 만들고 기본/방어막 유지/피격 반응을 촬영했다. 캡처는 카메라를 확대한 실제 URP 렌더이며 HUD를 함께 포함한다. 방어막을 가리는 경로 화살표와 배경 `Falling Leaves`는 검증용 복제본에서만 숨기고 촬영했다. 원본 게임의 경로·낙엽 표현은 유지했다.
- `sustained.png`, `impact.png`: 원본 1280×960 캡처. `preview.gif`는 실제 연속 프레임의 확대 크롭에 비교 라벨만 추가했다. 실제 게임은 확대 정도에 따라 보이는 크기가 달라진다.
- 카탈로그 20종의 공유 원기둥 메시, 몸 대비 크기 여유, 위치 추적·이동·도발 거대화, 원본 재질 보존, 정지·만료·사망 숨김, 피격 파라미터, 셰이더 지원/컴파일을 검증했다.
- `results.txt`에 최종 결과와 에디터 시작 시 검색 인덱스 예외를 기록했다. Windows 빌드와 대규모 전투 성능은 미확인이다.
- 원본 프로젝트의 전투 코드·씬·에셋 참조는 이번 작업에서 수정하지 않았다. 공유 메시/재질은 기존 보드 해제 목록에 등록한다.
