# 이동속도 흐름 오라 검증

- Unity 6000.3.28f1 CLI가 프로젝트 복제본 `/tmp/be-speed-flow-validation`에서 `SpeedAuraValidation.Run`을 실행했다. 자동 검증 코드는 복제본에만 추가했다.
- 실제 GameScene의 단풍 스테이지에 이동속도 버프 유닛 3개를 배치했다. 첫째는 정지, 둘째·셋째는 이동·방향 전환·정지를 반복한다. 셋째에는 공격력과 방어막도 함께 적용했다.
- 카메라를 확대하고 비교를 방해하는 경로 화살표·배경 Falling Leaves를 복제본에서만 숨겼다. 원본 씬과 효과는 유지했다. `rest.png`, `moving.png`, `stopped.png`는 실제 URP 렌더 원본이며 `preview.gif`는 연속 프레임을 크롭하고 설명 라벨만 추가했다.
- 타이머·이동·모델 애니메이션을 일정 간격으로 진행했다. 효과는 실제 표시 위치의 이동량을 사용한다. 정지 후 수축, 90도 회전 추종, 델타 0 정지, 독립 만료 시 다른 버프 유지, 중첩 시 Renderer 재사용, 사망 숨김, 20종의 이동·거대화·하체 위치·원본 재질 보존을 검사했다.
- 기존 이동속도 입자 평면이 꺼지고 두 줄짜리 LineRenderer가 생성되지 않는지 확인했다. 공유 메시와 셰이더 지원/컴파일을 확인했다. 결과는 `results.txt`, 구현 해시는 `source-hashes.txt`에 있다.
- Windows 빌드와 대규모 동시 버프의 GPU 성능은 미확인이다. 도발·회복의 새 콘셉트는 적용하지 않았다.
