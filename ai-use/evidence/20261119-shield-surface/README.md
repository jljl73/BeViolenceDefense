# 몸에 붙는 방어막 1차 시안

- 사용자와 먼저 합의한 방향에 따라 방어막 하나부터 적용했다. 다른 버프의 입자 표현과 상태 UI는 이번에 수정하지 않았다.
- Unity 6000.3.28f1 CLI의 `/tmp/be-shield-surface-validation` 복제본에서 GameScene Play Mode 실행. 종료 코드 0.
- 같은 모델 3개를 통제된 위치에 배치했다. 왼쪽은 기본, 가운데는 방어막 유지, 오른쪽은 방어막과 피격 반응이다. GIF는 실제 Unity 렌더를 잘라 제목만 붙인 비교 화면이다.
- 방어막용 입자 평면을 비활성화하고 원본 메시/본을 공유하는 표면 Renderer로 교체했다. 원본 재질은 보존하며 얼굴은 약하게, 몸의 가장자리와 천천히 흐르는 부분은 선명하게 빛난다.
- 카탈로그 20종에 대해 표면 생성·메시/스킨 본 참조·원본 재질 보존을 확인했다. 정지, 만료, 사망 후 숨김, 피격 방향 값, 셰이더 지원/컴파일 검사 통과. 실제 움직이는 모든 공격 애니메이션을 각각 캡처한 것은 아니다.
- 변경 코드 5개가 검증 복제본과 일치함을 확인했다. C#·셰이더 컴파일 오류 없음. 에디터 검색 DB의 시작 예외는 관찰됐다.
- 다음 범위: 사용자 시각 피드백 이후 다른 버프의 표면 표현 확장. Windows 빌드, 최대 군중에서의 추가 메시 렌더 비용, 모든 스테이지/줌 거리의 시인성은 미확인.
